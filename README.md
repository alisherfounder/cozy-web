# Cozy – Smart House that Actually Cares Cares About its User

We implemented Raspberry PI, Arduino Nano, and created a Proof-of-Work level prototype for smart houses software. Also we built an n8n-like scenario constructor with Agentic workflow that could access and execute scenarios and tools, show statistics of usage of smart house, and be accessed via Telegram chatbot.
